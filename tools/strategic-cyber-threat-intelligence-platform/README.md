# Strategic Cyber Threat Intelligence Platform (SCTIP)

[Repository home](../../README.md) · [Tool catalogue](../../docs/TOOL_CATALOGUE.md) · [Access and use](../../docs/ACCESS_AND_USE.md)

## 1. Overview

**Provider:** ENDOSCOPE (ENDO)

**Service family:** Risk/Threat Monitoring & Cyberattack Management Services

An ENDOSCOPE-operated cloud service producing pilot-specific strategic cyber threat intelligence reports for offshore-wind environments. It uses pilot information and relevant AENAON services to examine security concerns, exposure, threat information and mitigation priorities.

Technical reference: *AENAON Open Call #1 Technical Annex*, v1.0 (7 August 2026).

## 2. Potential Open Call use

Review pilot-specific strategic intelligence, relevant adversary/TTP context and mitigation priorities as part of an agreed security or risk assessment activity.

## 3. Access and deployment

Authorised beneficiaries receive controlled REST/JSON API access to an organisation workspace in the ENDOSCOPE-operated service. Endpoint details and credentials are supplied through authorised onboarding. No self-managed deployment is included.

## 4. Getting started

Agree the pilot context, intended report use, permitted source information and organisation workspace with ENDOSCOPE. Obtain authorised API access and current interface documentation. Confirm which reports and exports are available for the agreed downstream workflow before planning an integration.

## 5. Inputs and outputs

- **Inputs:** Information from pilots and relevant AENAON services concerning security, exposure and threats, where agreed and permitted.
- **Outputs:** Contextual intelligence reports, relevant adversary/TTP information, mitigation priorities and agreed exports for downstream workflows.

## 6. Interfaces and dependencies

Controlled REST/JSON API access to an organisation workspace. Relevant intelligence may inform the [Risk Assessment Platform](../risk-assessment-platform/README.md) where agreed. No automated connection to other services, schema or report-generation schedule is asserted.

## 7. Documentation and resources

The responsible provider (ENDOSCOPE (ENDO)) supplies approved manuals, access instructions and technical resources where applicable to the authorised activity. Request current resources through the provider/project contact route below.

## 8. Limitations and authorised use

No self-managed deployment, source code, deployment artefacts, internal APIs or direct database access are included. Results reflect the intelligence available at the time of generation. Confirm permitted sharing and intended recipients of pilot reports; repository access is not access to restricted reports.

Follow the applicable project, Open Call and provider terms. Repository documentation, hosted service access, API access and downloadable software are separate arrangements. Never commit credentials or sensitive operational information. See [access and use](../../docs/ACCESS_AND_USE.md).
