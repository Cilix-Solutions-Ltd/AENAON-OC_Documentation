# Cyber Range Solution

[Repository home](../../README.md) · [Tool catalogue](../../docs/TOOL_CATALOGUE.md) · [Access and use](../../docs/ACCESS_AND_USE.md)

## 1. Overview

**Provider:** ZELUS

**Service family:** Security Awareness & Cyber Range Services

A cyber range and interactive training platform for designing, executing and evaluating cybersecurity exercises for wind-farm operators. It works alongside the Digital Twin & Virtualisation component to provide realistic simulated infrastructure and training environments.

Technical reference: *AENAON Open Call #1 Technical Annex*, v1.0 (7 August 2026).

## 2. Potential Open Call use

Run training scenarios, test detection rules, practise incident response, assess operator readiness and collect exercise telemetry in the agreed training environment.

## 3. Access and deployment

Access is provided through role-based operator accounts in provisioned environments. Platform administrators configure and launch scenarios. ZELUS agrees the beneficiary roles and environment; independently distributable binaries and unrestricted platform deployment must not be assumed.

## 4. Getting started

Agree exercise objectives, participants and permitted scenario inputs with ZELUS. Arrange a provisioned environment and operator accounts. Confirm that the Digital Twin dependency and relevant incident/detection inputs are available, then follow administrator-supplied instructions for the configured exercise rather than assuming beneficiaries can launch arbitrary scenarios.

## 5. Inputs and outputs

- **Inputs:** Relevant incident/detection scenario inputs and the simulated infrastructure context supplied through the Digital Twin component.
- **Outputs:** Exercise telemetry and results supporting scenario evaluation and operator readiness assessment.

## 6. Interfaces and dependencies

The [Digital Twin Solution](../digital-twin-solution/README.md) is a stated dependency. Role-based operator access and administrator-managed scenario configuration are described; no separate public API or transferable deployment package is specified by the baseline.

## 7. Documentation and resources

The responsible provider (ZELUS) supplies approved manuals, access instructions and technical resources where applicable to the authorised activity. Request current resources through the provider/project contact route below.

## 8. Limitations and authorised use

Operate within the provisioned scenario and assigned role. Do not assume unrestricted platform deployment or independently distributable binaries. Agree exercise data handling and telemetry use; training access does not authorise testing against live operational infrastructure.

Follow the applicable project, Open Call and provider terms. Repository documentation, hosted service access, API access and downloadable software are separate arrangements. Never commit credentials or sensitive operational information. See [access and use](../../docs/ACCESS_AND_USE.md).
