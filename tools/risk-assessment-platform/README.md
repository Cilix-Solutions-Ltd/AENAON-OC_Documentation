# Risk Assessment Platform

[Repository home](../../README.md) · [Tool catalogue](../../docs/TOOL_CATALOGUE.md) · [Access and use](../../docs/ACCESS_AND_USE.md)

## 1. Overview

**Provider:** PRIVACT

**Service family:** Threat & Risk Assessment Services

A proprietary platform for threat and risk assessment of offshore-wind digital infrastructures. It uses vulnerability information, threat intelligence, asset relationships and knowledge-graph risk models to examine individual and cascading risks, dependencies, potential consequences and mitigation strategies.

Technical reference: *AENAON Open Call #1 Technical Annex*, v1.0 (7 August 2026).

## 2. Potential Open Call use

Assess risk scenarios and propagation across an agreed infrastructure model, prioritise risks and examine mitigation strategies using available asset, exposure and intelligence context.

## 3. Access and deployment

PRIVACT hosts and operates the service. Selected beneficiaries receive controlled project-scoped access. Scoped REST API access may be available where agreed. Source-code distribution, self-managed deployment and internal interfaces are not included.

## 4. Getting started

Agree the assessment purpose, project scope and permitted asset/system model with PRIVACT. Confirm which exposure and intelligence inputs can be supplied and shared. Obtain workspace access and applicable instructions through onboarding. Request a scoped API arrangement only if needed and agreed; no endpoint or installation procedure is supplied here.

## 5. Inputs and outputs

- **Inputs:** Asset and system models, potentially xBOMGuard exposure information and relevant CTIP/SCTIP intelligence, subject to agreed access, sharing and compatibility.
- **Outputs:** Risk scores, prioritisation, risk propagation paths, knowledge-graph models, risk scenarios and reports.

## 6. Interfaces and dependencies

Project-scoped service access and scoped REST API access where agreed. Potential inputs from [xBOMGuard](../xbomguard/README.md), [CTIP](../cyber-threat-intelligence-platform/README.md) and [SCTIP](../strategic-cyber-threat-intelligence-platform/README.md) do not establish live integrations or automated transfers. Knowledge-graph outputs do not grant access to internal interfaces.

## 7. Documentation and resources

The responsible provider (PRIVACT) supplies approved manuals, access instructions and technical resources where applicable to the authorised activity. Request current resources through the provider/project contact route below.

## 8. Limitations and authorised use

No source-code distribution, self-managed deployment or internal interfaces are included. Agree input permissions and interpret results against the available model and evidence; the catalogue does not promise outcomes or automatic mitigation. Keep confidential infrastructure models and reports in agreed secure channels.

Follow the applicable project, Open Call and provider terms. Repository documentation, hosted service access, API access and downloadable software are separate arrangements. Never commit credentials or sensitive operational information. See [access and use](../../docs/ACCESS_AND_USE.md).
